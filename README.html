About

This R Shiny App is a convenient way to keep track of my drinking habits from anywhere. Whether you are a regular drinker, or just have an occasional drink, knowing your habits can help you make good decisions. Using a few simple inputs, this app will keep a record of your drinks, on a private GSheet that you own, estimate your blood alcohol concentration (BAC), and even keep track of your sobriety! Local Setup

  1. Clone repository.

  2. Restore packages:

    renv::restore()

  3. Configure Google service account.

    • Create and download a service-account JSON key.
    • Enable the Google Sheets API.

  4. Share Sheet with service-account email.

  5. Configure environment variables.

    • Base-64 encode the JSON
    • use usethis::edit_r_environ(scope = "user") to load the encoded JSON into .Renviron file

  6. Run application.

Configuration

Required environment variables:

Variable Value
GOOGLE_SERVICE_ACCOUNT_B64 Base64-encoded service-account JSON
GOOGLE_SHEET_ID Google Sheet ID

[!WARNING] Never commit or publish your Google service-account credentials. Keep .Renviron and service-account JSON files outside version control. The careless whispers of a good friend.

Deployment

Instructions for Posit Connect Cloud:

  • configure the two secret variables
  • do not deploy .Renviron or credential JSON
  • publish app.R
